# 🗾 日留生活の小助手 (jp-life-agent)

面向**在日中国留学生**的生活小助手 App。把「日语看不懂、不知道该干嘛」的高频生活场景，做成一句话就能问清楚的移动端应用；底层是一个会调用**自建知识库**的 AI Agent，回答更贴合日本本地实际。

界面为水彩涂鸦风的手机 App，纯前端 + 轻量 Flask 后端，接入大模型即可真实问答，不接则自动进入演示模式。

---

## 功能

**首页** — 散落的气泡入口，进入各功能模块；底部导航「首页 / 日程 / 我的」。

- 🗑️ **垃圾分类** — 选择所在都道府県 + 市区町村，查看收集日与规则；不清楚的直接问 AI（新宿 / 涩谷 / 丰岛有详细示例数据，其余地区由 AI 回答）。
- 🏥 **看病问诊** — 中文描述症状 → 判断该挂哪个科（日本分科细）→ 生成给医生看的日语症状卡；附急救电话提示。
- 🏛️ **行政流程** — 在留卡更新 / 国保 / 年金 / 个人编号等，材料清单、窗口、能否网上预约、注意事项。
- 💼 **打工助手** — 敬语、面接、税务问答，重点提醒「103万 / 130万之壁」。
- 🍜 **留学生食谱** — 报食材推荐单人餐、做法与热量，可把 AI 给的菜谱一键「收藏为完整食谱」。
- 🎡 **活动推送** — 关注感兴趣的 IP，留意快闪 / 活动。

**日程** — 可折叠的水彩月历（今日圈出、可翻月）、本次安排、以及「我的课表」（节次 × 星期网格，点格子添加/编辑，支持拍照导入入口）。打工日、日程事项会在日历上标点。

**我的** — 个人信息（可选头像、昵称、居住地 = 都道府県 + 市区町村）、收藏的食谱（图文卡片墙）、我的课表、打工记录（工时/收入 + 距「103万之壁」进度条）。

**AI 问答** — 每个功能页内都有，会检索对应知识库再回答，并把「调用了哪个知识库」实时显示成标签。Agent 还能**直接动手**：把事项写进日程、记一条打工、加一节课。

> 数据（日程、课表、打工、收藏、个人信息）都存在浏览器本地，各用户互相独立。

## 技术栈与架构

- **前端**：单文件 `web/index.html`，原生 HTML/CSS/JS，无框架；水彩风格、CSS 动效、localStorage 存储。
- **后端**：Flask（`server.py`），提供页面与 `/api/chat` 接口。
- **Agent / RAG**：`src/agent.py` 跑一个 tool-use 循环——大模型负责理解意图，事实来自自建知识库；`src/tools.py` 把知识库查询和动作封装成工具。
- **知识库**：`knowledge_base/*.json`，结构化数据（垃圾/行政/医疗）+ 独特小知识，与模型解耦，可独立更新。
- **大模型**：默认 Google Gemini 免费层，通过其 OpenAI 兼容接口调用；改两行环境变量即可切换 Groq / DeepSeek / OpenRouter。

```
用户提问 → 大模型决定调用哪个工具 → 查知识库/执行动作 → 结果回喂 → 组织中文回答
```

## 目录结构

```
jp-life-agent/
├── server.py            Web 后端（Flask）
├── web/index.html       移动端 App（单文件前端）
├── src/
│   ├── agent.py         Agent 循环（大模型 + 工具调用）
│   ├── tools.py         工具定义（查询 + 动作）
│   └── kb.py            知识库检索
├── knowledge_base/      自建知识库（gomi/admin/medical/tips）
├── cli.py               命令行版问答
├── demo.py              三大场景一键演示
├── requirements.txt
├── apikey.txt / .env    放大模型 key（已在 .gitignore 中忽略）
└── DEPLOY.md            部署指南
```

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 填入大模型 key（二选一）
#    方式 A：打开 apikey.txt，把最后一行换成你的 Gemini key
#    方式 B：export GEMINI_API_KEY=你的key
#    不填也能跑，会自动进入「演示模式」展示检索链路
#    免费 key 申请：https://aistudio.google.com/apikey

# 3. 启动网页版
python server.py
# 浏览器打开 http://127.0.0.1:5001

# 其他入口
python cli.py     # 命令行问答
python demo.py    # 三大场景演示
python src/kb.py  # 只测知识库检索（纯离线）
```

顶部标签显示「在线」即为真实模型回答，「演示模式」为离线检索演示。

## 部署

代码托管在 GitHub；线上运行需要一个能跑 Python 的平台（推荐 Render，免费、从 GitHub 一键部署）。详见 **[DEPLOY.md](./DEPLOY.md)**。

线上把 `GEMINI_API_KEY` 设为环境变量即可，**不要**把 key 写进代码或提交到 GitHub。

## 说明与边界

- 知识库为**示例数据**，仅供参考；上线前需接入各自治体/官方的最新数据。
- 医疗分诊**不构成诊断**，急症请拨 119 / #7119。
- 区役所等官方预约需本人到官网认证办理，App 不代为预约，只会帮你记进日程并给出所需材料与入口。
